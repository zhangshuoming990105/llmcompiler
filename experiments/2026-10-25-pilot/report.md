# 第一轮基础链路验证（2026-10-25）

这一轮验证 skill、agent CLI、变量绑定、布局、分块汇编与差分测试能否连通。
后续研究重点转向长函数的递归拆分、局部细化和增量重编译；本轮的小函数
准确率仅作为基础检查。递归版本的结果另存于 `../2026-10-25-recursive/`。

全部执行于 arm64/macOS，使用 Apple Clang 21.0.0。模型生成阶段没有调用工具，
控制器独立编译参考 C 和测试驱动。生成没有收到测试反馈，也没有修复轮次。

| 执行方式 | 用例通过数 | 差分检查数 |
|---|---:|---:|
| Clang 常规编译对照 | 6/6 | 7,642 |
| Clang 变量重命名对照 | 6/6 | 7,642 |
| Codex direct | 6/6 | 7,642 |
| Codex LEGO，同一上下文生成各块 | 6/6 | 7,642 |
| Codex LEGO，逐块独立调用，仅结构体用例 | 1/1 | 1,000 |
| Pi LEGO，同一上下文，仅 gcd 用例 | 1/1 | 5,225 |

六个用例分别是归档的 gcd、位逻辑、switch 函数，以及新增的同名变量遮蔽与
嵌套循环、带 stride 的数组修改、结构体数组偏移用例。归档函数的 C 源码未改动，
测试输入为新编写的确定性输入。因此，这不是旧 ExeBench IO 或论文准确率的重现。

Codex CLI 为 0.162.1，使用已有配置；执行事件没有返回实际服务端模型 ID。
运行后读取到的本机配置为 `gpt-6-astra` / `xhigh`，该配置读取不等于服务端模型确认。
Pi CLI 为 1.2.0，事件报告的模型标识为 `mco-6`。两者未做同模型、同运行时的性能比较。

Codex direct 的生成调用合计 136.28 秒，LEGO bundle 合计 138.05 秒。
CLI 报告的输入 token 分别为 111,684 和 126,287，输出 token 分别为 3,807 和 4,688。
这些数值包含 CLI 上下文开销，且部分实验在同机并行；不构成严格延迟基准。
